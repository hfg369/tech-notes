# 关于本站

## 一份公开的学习记录

这里记录数据工程、软件工程和 AI Agent 方向的学习过程。内容以小型例子和问题复盘为主，目标是把术语变成可以运行、观察和验证的步骤。

本站不把教程跑通、计划中的实验或开源项目的能力，写成个人工作经历。文章中的状态会明确标注：已经写成的笔记只说明完成了这篇整理；标注“计划”的内容仍需要实际实验和结果记录。

## 记录一篇文章的方式

每个主题尽量回答四个问题：

1. 这件事要解决什么问题？
2. 最小可运行的例子是什么？
3. 哪些观察能支持判断？
4. 改动之后，怎样证明结果没有被悄悄改变？

如果答案依赖具体版本、数据规模或运行环境，会把这些前提写出来。没有测量过的性能、准确率或业务收益，不使用看起来精确的数字代替。

## 当前关注方向

学习路线暂时围绕三条线展开：

- **数据基础：** Python、SQL、关系型数据模型与数据质量。
- **数据工程：** Spark、实时处理、索引与可重跑的数据管道。
- **Data Agent：** 工具调用、决策循环、业务口径、评价与失败恢复。

详细的阶段安排见 [学习路线](/roadmap)。

文章会优先链接官方文档和可复现的示例。若发现链接失效、概念表述不准确或示例不能运行，欢迎在 [GitHub 仓库提交 Issue](https://github.com/hfg369/tech-notes/issues)；修正时会保留问题的上下文与验证方式。
