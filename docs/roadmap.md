# 学习路线

> **状态说明：以下内容全部是学习计划，不是已完成经历或工作成果。**完成一个阶段的标准，是有可运行的代码、可核对的结果和一段真实复盘。

## 目标

希望逐步具备这样的能力：拿到一个数据或 Agent 需求时，能够先定义目标和数据口径，再设计处理流程，写出可运行实现，定位失败原因，并用测试或实验说明结果是否可信。

配套的开源项目入口见 [GitHub 项目推荐](/projects)。主路线是 `jaffle-shop → Zoomcamp/Spark → Vanna`，LangGraph 按需加入，Flink 放到实时数据阶段选修。

## 四个阶段

### 01 · Python 与 SQL 基础（计划中）

**要学：** Python 文件、函数、异常和调试；SQL 的过滤、聚合、Join、窗口函数和事务基础。

**要做：** 用 SQLite 完成一组订单分析查询，主动加入重复记录、空值和状态变更；为每条查询写出手算结果和验证 SQL。

**阶段产物：** 一个能重复运行的练习目录，以及一篇解释数据粒度和指标口径的复盘。

### 02 · 数据工程链路（计划中）

**要学：** 原始数据接入、清洗、分层建模、调度、重跑、数据质量检查；Spark 的 DataFrame、Shuffle、分区和执行计划。

**要做：** 将订单数据从原始文件处理为明细表和汇总表；记录一次数据倾斜或小文件问题的证据和处理过程。

**阶段产物：** 一条可重跑的数据管道，带有样例数据、质量检查和运行说明。

### 03 · 实时数据与检索（计划中）

**要学：** Flink 的事件时间、窗口、状态与检查点；Elasticsearch 的 Mapping、过滤、聚合和批量写入。

**要做：** 模拟订单事件流，加入乱序、迟到和重复事件；把分析结果写入索引，并与 SQL 结果核对。

**阶段产物：** 一份明确记录数据源、状态、下游写入语义的实验报告。

### 04 · Data Agent 与工程化（计划中）

**要学：** 工具调用、结构化输出、状态管理、只读查询、评价集、日志和人工接管。

**要做：** 在订单分析表上实现一个受控问数流程：问题澄清 → 查询生成 → 安全检查 → 执行 → 结果核对 → 回答；收集失败案例后再改进。

**阶段产物：** 一个可复现的 Data Agent 作品，包含架构说明、测试问题、已知限制和运行演示。

## 进入下一阶段的检查

不要用“看完课程”作为唯一标准。每一步开始前，先检查上一步是否能够做到：

- 不看教程也能解释核心数据结构或流程；
- 修改一个输入条件后，知道应当改动哪里；
- 遇到错误时，能定位到具体步骤或证据；
- 能用小数据核对结果，而不是只看程序有没有报错。

## 本周可以开始的最小任务

运行 [SQL 一对多示例](/notes/sql-one-to-many)，先预测三条查询的结果，再执行仓库中的验证脚本。完成后，把一个字段或一条业务规则改掉，观察哪些结果需要随之变化。这个任务很小，但会同时练习 SQL、数据粒度和验证习惯。
